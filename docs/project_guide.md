# 房间点云组合项目方案与任务说明

这是把伙伴提供的 Task 1 项目与我们的墙面粗糙度项目组合后的独立仓库。输入一个完整房间点云即可依次分墙、识别门窗、检查墙角、计算墙面 RMS，并生成 Word 与 HTML 报告。无需先由人手工选择四个点。

## 一 总体任务与组合原则

课程 Task 1 的主要结果是房间长宽高、门窗宽高和墙面粗糙度，还需文献综述、方案说明、测量误差评价及课程要求的展示。生成测量报告只是成果的一部分，不等于已经完成所有课程要求。

| 模块 | 采用哪一部分 | 你的工作边界 |
|---|---|---|
| 输入与总控 | 伙伴 Task 1 | 沿用读取、单位、坐标、profile、结果目录与网页入口 |
| 分墙支持点 | 我们的 Efficient RANSAC | 完整有限点输入、墙体规则、保留原始支持点与点号 |
| 门窗与深度 | 伙伴 Task 1 | 保留沿墙剖面、边界、尺寸和窗框深度分析 |
| 墙角与房间尺寸 | 伙伴 Task 1 | 保留四墙闭合、顶面覆盖、三平面相交和角点复核 |
| 墙面粗糙度 | 我们的无滤波方法 | 原始坐标 SVD 拟合、正交距离 RMS、可追溯误差评估 |
| 结果与报告 | 伙伴 Task 1 加适配 | 沿用报告结构，输出整墙 RMS 和原始点来源 |

你的核心责任仍是“完整点云 → 原版墙支持点 → 墙面 RMS”及其准确性评价。队友继续负责门窗语义、房间/洞口尺寸与墙角正确性。组合代码把接口串起来，但不替代实测真值和人工复核。

## 二 怎样与流程图逐项对应

第一步，输入单房间 PCD 或带 x,y,z 表头的 CSV，明确 m/mm 和向上方向。原始点号按文件点记录从 0 计数，不是 PCD 文本的行号。非有限行保留编号位置但不参与原版检测。

第二步，在完整有限点云上用原版 Efficient RANSAC 检测平面，再以方向、尺寸、接地规则筛出墙候选。相近共面片段只对已有支持点取并集。“取回原始点”只是根据点号取 XYZ，不在平面附近补点。

第三步，按伙伴项目同时走三条路径：门窗剖面识别与边界拟合；原始墙点归属；四墙闭合、顶面覆盖和结构角点检查。门窗检测结果转换为洞口中心、四角、宽高和深度信息。

第四步，按伙伴项目剔除检出洞口投影内的墙支持点，获得可用墙点；没有检出洞口就保留全部归属点。可用墙点用于整墙计算。检测空洞仍可能是遮挡，所以空间排除规则及洞口身份需核验。

第五步，结构可靠时输出整墙四角；缺少闭合或可靠顶面时将该墙的整墙 RMS 标为待复核。

第六步，在指定四角的二维投影区域内对原始点重新 SVD 拟合，计算 RMS 并生成报告。

本次沿用伙伴墙角规则，没有使用独立框架更严格的 250 mm 最大角点支持距离门槛。伙伴对超过 50 mm 的角点外推给出警示；这只是角点证据提示，不是 RMS 的厚度过滤。

## 三 输入输出与 RMS 定义

| 内容 | 约定 |
|---|---|
| 必需输入 | 完整单房间点云、坐标单位、向上方向；不用手工四角 |
| 可选输入 | 用于配置四个接口的 profile |
| whole | 排除检出洞口后，整墙结构四角内支持点的 RMS |
| 文件输出 | summary.json、CSV、原始点号与残差、立面图、Word 和 HTML |

SVD 用来找到点集的最佳拟合平面。每个点到平面的正交距离记为 d，RMS 是 Root Mean Square，即 sqrt(mean(d²))。坐标内部用米计算，再乘 1000 输出毫米。

墙面测量不做 SOR/ROR、平滑、残差裁剪、50 mm 法向恢复或 50 mm 厚度筛选。ROI 文件的 slab_half_thickness_mm 是 null。已检出洞口的几何边界排除属于区域定义；门窗 8 mm 面层和窗框深度切片属于伙伴检测模块，不影响 support 点集。

原接口字段 expanded_indices 在适配后只是兼容名称，值精确等于原版支持点索引。每域 residuals.npz 保存原始点号和带符号距离，可以复算 sqrt(mean(signed_mm²))。native_supports.txt 和构建/输入指纹用于检查点来源。

## 五 官方指定墙的 GT 对照

| 房间墙号 | 官方 GT mm | 整墙 RMS mm | 计算值减 GT mm | 相对绝对差 |
|---|---|---|---|---|
| M04 W01 | 1.8 | 1.351416 | -0.448584 | 24.92% |
| M26 W03 | 1.0 | 1.142036 | +0.142036 | 14.20% |

GT 来源是课程点云说明 readme(1).md 的 Ground-Truth Measurements：M04 为配图标出的墙，1.8 mm；M26 为门对面的墙，1.0 mm。数据说明称其为人工测量值。当前候选墙对应分别为 W01、W03，墙号是本次算法运行编号，不能跨不同算法直接照搬。

相对绝对差 = |计算值 − GT| / GT × 100%。这里使用整墙 RMS。M04 低于参考值，M26 高于参考值；较低 RMS 不等于更准确。

官方资料缺少精确测区四角和完整测量规程，当前不能证明官方区域与整墙计算区域完全一致，因此这张表应称为官方参考差异，不应直接称为同测区真实误差。下一步应由小组确认墙身份和测区边界，再评价点集 Precision/Recall/IoU、同测区 RMS 误差、房间/洞口尺寸误差及失败率。

安装顺序：Git 克隆 → Python 虚拟环境与 requirements.txt → native_backend/scripts/fetch_native.py 下载固定版本原版代码 → native_backend/native/build.py 编译 → inspect_room.py 运行。Windows 网页入口为 run.cmd。详细命令在 README。

运行示例为 python inspect_room.py room.pcd --unit m --up 0 0 1 --out results/new_run。每次使用新输出目录。summary.json 记录输入和算法来源，完整实验总报告见 docs/Task1_Evaluation.docx。
